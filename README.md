# Customer Churn Prediction Using Machine Learning

## Project Overview

This project focuses on predicting customer churn in a telecom company using machine learning. The goal is to use customer information and service details to predict whether a customer is likely to leave the company.

## Dataset

The project uses the Telco Customer Churn dataset.

The dataset includes information such as:

- Customer demographics
- Services used by customers
- Contract type
- Tenure
- Monthly charges
- Total charges
- Churn status

## Machine Learning Models

Two classification models are used in this project:

- Logistic Regression
- Random Forest

## Project Steps

1. Load and understand the dataset
2. Clean and preprocess the data
3. Handle missing values
4. Explore the data using visualizations
5. Create and encode features
6. Split the data into training and testing sets
7. Train the machine learning models
8. Evaluate the models
9. Make sample churn predictions
